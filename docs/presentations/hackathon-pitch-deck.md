## Slide 2: The Problem
**Visual:** Split screen. Left side: "Chaos" (Discord screenshots, suspicious DMs, bank transfers). Right side: "Friction" (Lawyers, 15% broker fees, months of negotiation).
**Headline:** The "Micro-Exit" Gap
**Bullet Points:**

*   **Zero Trust:** Buyers fear sending crypto first; Sellers fear handing over code first.
*   **Due Diligence Nightmare:** "Verify revenue?" "Check the code?" Manual, expensive, and error-prone.
*   **Result:** A massive, illiquid asset class of profitable micro-SaaS and content sites.

## Slide 4: How It Works (The Core Loop)
**Visual:** 3-Step Flow Chart.
**Step 1: Verify (AI Agents)** 
*   Seller lists a project. 
*   **AgentKit** bot scans the GitHub repo and API keys to verify "Proof of Revenue" and "Proof of Code".
**Step 2: Secure (Smart Escrow)**
*   Buyer deposits **IDRX** (Stablecoin) into the Smart Vault. 
*   Funds are locked.
**Step 3: Swap (Atomic Transfer)**
*   Seller transfers assets. Agent verifies receipt.
*   Smart Contract releases funds to Seller and IP Rights NFT to Buyer.
